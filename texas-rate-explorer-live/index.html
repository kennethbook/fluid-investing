    Analysis method

    Each export is restricted to the professional-rate observations present in the supplied files. For every payer × matched rate entity × CPT code, duplicate raw negotiated-rate rows are collapsed to the median of unique rates. Statewide percentiles are then calculated within payer × provider type × CPT code cells.

    The provider type is inferred from the associated NPI/taxonomy evidence in the exports. The map uses matched rate entities and their available practice geography. A provider can lead to the same contracting entity as another provider, which is why independent entity count matters more than NPI count for inference.

    Statistical caution: a larger NPI pull improves coverage but does not by itself establish statistical significance. For stable percentile work, prioritize more independent contracting entities in each payer × provider-type × code cell and avoid letting one large TIN dominate a region.
